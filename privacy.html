My Dashboard 개인정보처리방침

시행일: 2026년 9월 18일

1. 수집하는 정보

My Dashboard(이하 "프로그램")는 개발자가 운영하는 서버로 어떠한 개인정보도 수집·전송하지 않습니다.

2. 구글 드라이브 연동

사용자가 "구글 드라이브 연결"을 선택한 경우에만 다음과 같이 동작합니다.

  • 요청 권한은 drive.appdata(앱 전용 숨김 폴더) 하나뿐입니다.
  • 위젯 배치, 할 일, 메모, 설정 및 사용자가 업로드한 파일은 사용자 본인의 구글 드라이브 앱 전용 폴더에만 저장됩니다.
  • 프로그램은 사용자 드라이브의 다른 파일을 열람하거나 수정할 수 없습니다.
  • 개발자는 사용자의 데이터에 접근할 수 없습니다.

3. 컴퓨터에 저장되는 정보

로그인 유지를 위한 인증 정보는 사용자의 컴퓨터에 Windows 계정으로 암호화되어 저장되며, 외부로 전송되지 않습니다.

4. 연결 해제 및 삭제

  • 프로그램의 [연결 해제] 버튼으로 언제든 연동을 끊을 수 있습니다.
  • 구글 계정 설정(myaccount.google.com/permissions)에서도 권한을 취소할 수 있습니다.

5. 문의

프로그램 관련 문의는 배포처 GitHub 저장소의 Issues를 이용해 주세요.

This app requests only the drive.appdata scope and stores data exclusively in the user's own Google Drive app-data folder. The developer operates no server and collects no personal data.
